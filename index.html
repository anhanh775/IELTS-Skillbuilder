IELTS Short Writing Practice

IELTS Writing Task 2, Band 3.5 to 4.0+. Topic: social media and teenagers.

Essay question

Some people think that social media is bad for teenagers. Do you agree or disagree?

In Task 2 you write about 250 words: Introduction (about 40), Body 1 (80 to 100), Body 2 (80 to 100), Conclusion (30 to 40). Each body paragraph is built from good sentences, so we practise sentences first.

Brainstorm your ideas. Write your ideas here. Then we will discuss them with the class. You will use them in the Write tab.

Model paragraph

Social media is not bad for teenagers because it is useful in two ways. The main reason is that many students live far from their relatives, so they can talk to them online every day. In addition, teenagers can learn new things from videos, which are free and easy to watch. For example, my cousin learned to cook by watching short videos on TikTok, and now she makes dinner for her family every weekend. As a result, she feels more independent. Therefore, social media is a useful tool for young people.

T topic sentence, E explanation, Ex example, R result, L link back to the question. About 90 words.

Common mistakes

MistakeWrongCorrect

Missing beSocial media popular.Social media is popular.
AgreementShe use Instagram.She uses Instagram.
PluralMany teenager spend time online.Many teenagers spend time online.
Word orderTeenagers every night chat with friends.Teenagers chat with friends every night.

Build a paragraph: TEEL

PartWhat it doesIn the model
Topic sentenceGives your main idea and answers the question.Social media is not bad for teenagers because it is useful in two ways.
ExplanationSays why. One or two sentences.The main reason is that many students live far from their relatives, so …
ExampleGives a real, specific example.For example, my cousin learned to cook by watching short videos …
Result / LinkShows the result and connects back to the question.As a result, … Therefore, social media is a useful tool …

One paragraph, one main idea. Use your own words and do not copy the question. Every sentence must support the topic sentence. Do not learn a paragraph by heart.

Useful language

Easy sentence patterns

S + be + adjectivedescribe something
Social media is useful for teenagers.
S + V + Osay what people do
Teenagers use social media every day.
S + can + Vsay what is possible
Teenagers can learn new things online.
S + V + because + S + Vgive a reason
Teenagers like social media because it is free.
S + V, so + S + Vshow a result
Many students live far away, so they use video calls.
S + V, but + S + Vshow contrast
Social media is fun, but it can waste time.
S + spend + time + on + nountalk about habits
Many teenagers spend too much time on social media.
S + help(s) + someone + (to) + Vsay the benefit
Social media helps teenagers keep in touch with friends.
I agree / disagree that + S + Vgive your opinion
I agree that social media is useful for teenagers.

S = subject (who or what). V = verb. With he, she, it, add -s to the verb: She uses Instagram.

Linking phrases for a paragraph

The main reason is that + S + Vexplain
The main reason is that many students live far away.
In addition, + S + Vadd an idea
In addition, teenagers can learn new things.
For example, + S + Vgive an example
For example, my cousin learned to cook online.
As a result, + S + Vshow a result
As a result, she feels more independent.
Therefore, + S + Vlink back to the question
Therefore, social media is useful for young people.

More choices: Moreover, For instance, This means that, In conclusion. Use a variety. Do not repeat the same one every time.
